# 可视化规范（VISUALIZATION_SPEC）

## 1. 页面布局（桌面优先）

```
┌────────────────────────────────────────────────────────────────┐
│ 顶栏：Logo「C Visualizer」│ 示例库下拉 │ Run ▶ ‖ ⏸ │ ◀ 上一步   │
│       下一步 ▶ │ ↻ 重新开始 │ 速度 │ 第 i / N 步                │
├──────────────────────────────┬─────────────────────────────────┤
│ 代码编辑器（左上，约 55% 高） │ 变量监视器（右上）               │
│  · 当前行高亮                 │  · 按作用域分组                  │
│  · 错误行标记                 │  · 变化值高亮                    │
├──────────────────────────────┤  · 指针显示 p → #n (x)          │
│ 控制流面板（左下）            ├─────────────────────────────────┤
│  · 当前步骤控制流事件         │ 内存 / 数组面板（右中）          │
│  · 最近事件轨迹               │  · 数组格子（下标+值）           │
│                              │  · 指针指向示意                  │
├──────────────────────────────┼─────────────────────────────────┤
│ 步骤说明（底部，显著字号）    │ 调用栈（右下）                   │
├──────────────────────────────┴─────────────────────────────────┤
│ 时间轴滑块（0..N-1）                 │ 输出面板（printf 结果）  │
└────────────────────────────────────────────────────────────────┘
```

- 编辑器：CodeMirror 6 + `@codemirror/lang-cpp`（C 高亮）。
- 运行前可编辑；运行后编辑器仍可编辑，但查看的是旧步骤，「运行」后刷新。

## 2. 代码高亮

- **当前行**：背景高亮（琥珀色半透明）+ 行号加亮；多行语句覆盖 line..endLine。
- **错误行**：红色波浪线/背景 + 行号标红；点击错误列表跳到该行。
- 高亮数据只来自 `step.line / step.endLine`。

## 3. 变量监视器

- 分组：`全局` → `函数名（帧 N）` → `块（第 x 行）` / `for（第 x 行）`，与快照 scopes 对应；仅显示存活作用域。
- 每个变量一行：`名称` `类型` `值`。
  - int：`10`；char：`'A' (65)`；float/double：最多 6 位有效数字；
  - 未初始化：`未初始化`（灰色斜体）；
  - 指针：`#3 (x)`（反查变量名，无名为裸地址）；
  - 数组：折叠为一行 `int[5]`，展开显示在内存面板（此处显示首地址）。
- **变化高亮**：与上一步快照对比（`step.changed.addresses`）：新出现的变量整行绿色；值变化的单元黄色脉冲动画；消失的作用域在下一条步骤自然不再显示。

## 4. 内存 / 数组面板

- **数组格子**：`a: int[5]` 标题 + 横向格子序列，每格 `下标: 值`；刚被写入的格子黄色高亮。
- **指针示意**：每行一个指针变量 `p ──▶ #3 (x)`；指向数组元素时显示 `p ──▶ a[2] (#12)`。
- 无数组/指针时显示占位说明「当前没有数组或指针」。

## 5. 控制流面板

- **当前事件区**：本步 `flowEvents` 渲染为流程行，例：
  - `判断 i < 5 → 真` → `进入循环体`
  - `&& 左侧 = 0（假）` → `短路：右侧 func() 不执行`
  - `switch x = 2` → `命中 case 2`
  - `case 2 结束，无 break` → `穿透到 case 3`
  - `goto LOOP` → `第 10 行 → 第 3 行`
  - `调用 factorial(4)` / `factorial 返回 24 → 回到 main`
- **轨迹区**：最近 ~8 条历史事件倒序排列（淡色），便于回看刚走过的路径。
- 循环回边（condition 再次为真→回到 body）以「↻ 回到循环体」样式强调。

## 6. 调用栈面板

- 纵向堆叠：栈底在最下（main），当前帧高亮。
- 每帧：`函数名(实参值列表)` + `调用自第 N 行`。
- 程序未开始：`（尚未调用 main）`；结束后：`（已返回）`。
- 递归时多帧同名 + 不同参数值，配合行号直观展示递归深度。

## 7. 步骤说明（教学解释）

- 底部固定说明区，显著展示当前步 `description`，例如：
  - 「声明变量 a（int），并初始化为 1。」
  - 「判断 a < b：1 < 2，条件成立，进入 if 分支。」
  - 「&& 左侧为 0（假），根据短路规则，右侧 factorial(4) 不会执行。」
  - 「执行 i++：i 从 2 变为 3。」
  - 「switch 表达式结果为 2，因此进入 case 2。」
  - 「goto 使程序跳转到标签 LOOP（第 3 行）。」
  - 「调用 factorial(4)：进入第 2 层递归，形参 n = 4。」
- 生成规则见 `explain.ts`：纯模板 + 数值插值，禁止 AI/随机。

## 8. 时间轴与控制

- 滑块：0..N-1，拖动即 `jumpTo(i)`；按钮禁用态正确（第 0 步时「上一步」禁用等）。
- 播放：`setInterval` 按速度档（0.5/1/2/4/8 步每秒）推进；到末尾自动停止。
- 步数指示：`第 12 / 87 步`；终止步骤显示状态徽标（✅ 完成 / ⚠ 步数上限 / ❌ 运行错误）。
- 键盘：←/→ 步进，空格播放/暂停（编辑器未聚焦时）。

## 9. 示例库

- 示例内容见 `src/examples/index.ts`，覆盖 SUPPORTED_C §4 全部验收场景。

## 10. 错误呈现

- 编译错误：顶栏下方红色横幅列出（`第3行第11列：...`），编辑器内标记；不产生步骤。
- 运行时错误：终止步骤以说明区红色样式 + 状态徽标呈现，调用栈/变量保持错误发生时刻的快照。
