# 需求规格（REQUIREMENTS）

> 本文档定义 v1.0 的功能需求（FR）与非功能需求（NFR）。支持范围的技术细节见 `SUPPORTED_C.md`。

## FR-1 代码输入

- FR-1.1 提供代码编辑器（CodeMirror 6，C 语法高亮）。
- FR-1.2 内置示例库（≥19 个），每个示例含：标题、知识点、代码、说明；一键载入。
- FR-1.3 编辑器内容可随时修改；修改后需重新「运行」才能看到新步骤。

## FR-2 编译（解析 + 检查）

- FR-2.1 点击「运行」后先解析：语法错误以 行:列 + 中文消息 列出，不出步骤。
- FR-2.2 语义检查：不支持的 C 特性给出「行:列 + 特性名 + 替代建议」。
- FR-2.3 任何编译/运行错误都不得导致页面崩溃（隔离在 try/catch 边界内）。

## FR-3 执行与控制

- FR-3.1 `Run`：解析并预计算全部执行步骤（每步含快照），定位到第 0 步。
- FR-3.2 `Next` / `Previous`：前进 / 后退一步；`Previous` 通过读取上一步快照实现，绝不重新推演。
- FR-3.3 `Restart`：回到第 0 步（不重新解析）。
- FR-3.4 `Pause` / `Play`：自动播放与暂停，速度可调（约 0.5～8 步/秒）。
- FR-3.5 时间轴：滑块跳转到任意步骤；显示「第 i / N 步」。
- FR-3.6 程序结束 / 运行时错误 / 触发保护上限时进入终止态并有明确提示。

## FR-4 可视化面板

- FR-4.1 代码行高亮：当前步骤对应的源码行必须高亮。
- FR-4.2 变量监视器：按作用域分组（Global / 函数 / 块），显示 名称、类型、值；与上一步相比发生变化的值必须视觉突出。
- FR-4.3 内存/数组面板：一维数组渲染为格子（下标+值）；指针渲染为「p → #地址 (变量名)」。
- FR-4.4 调用栈面板：从栈底到栈顶显示全部帧（函数名、参数、返回值位置），当前帧高亮。
- FR-4.5 控制流面板：显示当前步骤的控制流事件（条件判断结果、分支走向、循环回边、break/continue 跳转、goto 来源/目标、switch 匹配与穿透、调用/返回、短路）。
- FR-4.6 输出面板：显示 printf 的输出内容。
- FR-4.7 步骤说明：每步显示自动生成的中文教学说明（确定性规则，无 AI）。
- FR-4.8 表达式求值展示：当前步骤内按求值顺序展示子表达式「源码 → 值」；短路未求值的右侧必须标注「未执行」及原因。

## FR-5 错误与保护

- FR-5.1 错误分类：语法错误 / 不支持特性 / 类型错误 / 运行时错误 / 死循环保护。
- FR-5.2 死循环保护：执行超过 10000 步自动停止并提示；调用深度超过 100 报错；解释器墙钟超 10 秒强制终止。
- FR-5.3 除零、空指针解引用、未初始化读取等运行时错误在对应步骤给出定位与解释。

## FR-6 教学 子集（概要）

支持：int/char/float/double、变量声明/初始化/赋值、算术与比较与逻辑运算符（含 ++/--、复合赋值）、短路求值、if/else、switch（case/default/break/穿透）、for/while/do-while、break/continue、一维数组、函数（参数/返回值/局部变量）、递归、goto/label、基础指针（& 与 *）、内置 printf。
细则与否定清单见 `SUPPORTED_C.md`。

## NFR 非功能需求

- NFR-1 纯前端：Vite 构建，静态部署即可运行；无后端、无遥测。
- NFR-2 技术栈：React + TypeScript（strict）+ Vite；解析用 web-tree-sitter + tree-sitter-c。
- NFR-3 质量：`lint`、`typecheck`、`test`、`build` 四项全部通过才可发布；解释器/解析层单元测试覆盖每个子集特性与每类错误。
- NFR-4 性能：10000 步以内的教学程序，运行预计算应在 2 秒内完成；UI 操作（Next/Prev/跳转）应即时响应。
- NFR-5 语言：界面与文档为中文；代码注释为中文。
- NFR-6 兼容：最新版 Chrome / Edge 桌面端。
- NFR-7 可维护：文档与实现同步更新（见 `ROADMAP.md` 每个 Phase 的出口条件）。
