# C Visualizer — 产品说明

## 一句话定位

C Visualizer 是一个面向 C 语言初学者的**代码执行可视化教学工具**：用户在浏览器中输入 C 代码，逐语句执行，直观观察变量、表达式、条件、循环、数组、函数调用栈、switch、goto、指针等状态如何一步一步变化。

## 目标用户

- 正在学习 C 语言第一门课的学生（大一/培训/自学）。
- 需要「看得见」执行过程的教师（课堂演示）。
- 对指针、递归、短路求值等抽象概念感到困难的初学者。

## 核心价值

1. **教学优先，不是编译器**：不追求完整 ISO C，专注一个清晰定义的「C 教学子集」（见 `SUPPORTED_C.md`），保证子集内行为 100% 正确、可解释。
2. **每一步都有解释**：每个执行步骤自动生成简短中文说明（确定性规则生成，不依赖 AI API）。
3. **完全本地运行**：纯浏览器端执行（wasm 解析器 + JS 解释器），不依赖本机 C 编译器、不上传代码。
4. **时间可回溯**：所有步骤预计算并保存快照，支持 Next / Previous / Restart / 跳转到任意步骤，回退不是「猜」出来的。

## 核心体验流程

```
输入/选择示例代码 → 点击「运行」→ 逐条步骤查看：
  代码行高亮 + 变量变化高亮 + 内存格子 + 调用栈 + 控制流轨迹 + 中文说明
```

## 明确不做（v1.0）

- 不做完整 C 编译器 / 不生成机器码。
- 不支持 struct / union / enum / typedef / 多维数组 / 动态内存（malloc）/ 位运算等（详见 `SUPPORTED_C.md`）。
- 不提供 AI 讲解 / 联网功能。
- 不承诺教学规模之外的执行性能（步骤上限 10000 步）。

## 成功标准（v1.0）

- 典型教学代码（变量、if、switch、循环、短路、数组、函数、递归 factorial、goto、基础指针）均可正确逐步可视化。
- Run / Pause / Next / Previous / Restart / 跳转全部可用。
- 错误代码（语法错误、不支持特性、运行时错误、疑似死循环）给出准确定位与中文提示，绝不导致页面崩溃。
