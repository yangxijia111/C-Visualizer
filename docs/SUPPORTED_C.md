# C 教学子集支持范围（SUPPORTED_C）

> **本文档是「支持什么 / 不支持什么」的唯一权威来源。文档承诺的必须实现，未列出的一律不支持。**
> 版本：v1.0

## 1. v1.0 支持清单

### 1.1 类型

| 类型 | 支持 | 备注 |
| --- | --- | --- |
| `int` | ✅ | 32 位有符号语义（溢出环绕不做检测，按 JS 数值截断在 ±2^31 内） |
| `char` | ✅ | 字符字面量 `'A'`、`'\n'`、`'\t'`、`'\\'`、`'\''`、`'\0'`；算术中按 ASCII 码参与 |
| `float` / `double` | ✅ | 均按 JS double 存储；显示时最多保留 6 位有效数字 |
| `void` | ✅ | 仅用于函数返回类型 |
| 指针 `T *` | ✅ | 仅一层指针（`int *p`），仅指向已声明变量或数组元素 |
| 一维数组 `T[n]` | ✅ | n 为正整数常量表达式；元素类型为标量（int/char/float/double） |

### 1.2 变量

- ✅ 声明：`int a;`（未初始化的标量读取报运行时错误，模拟「未定义」）
- ✅ 声明并初始化：`int b = 10;` `int a[5] = {1, 2, 3};`（不全初始化则剩余为 0；`{0}` 合法）
- ✅ 空初始化数组：`int a[5] = {};`（等价全 0）
- ✅ 赋值：`a = b + 5;` `a = b = 1;`（连续赋值，右结合）
- ✅ 复合赋值：`+=  -=  *=  /=  %=`
- ✅ 一条语句多声明符：`int a = 1, b = 2, c;`
- ✅ 全局变量（初始化必须是常量表达式：字面量及字面量四则运算）
- ✅ 块作用域与同名遮蔽（内层遮蔽外层）

### 1.3 表达式与运算符

| 类别 | 运算符 | 备注 |
| --- | --- | --- |
| 算术 | `+  -  *  /  %` | `%` 仅整型；`/` 遵守 C 整数除法截断（`5/2==2`，`-7/2==-3`）；除数为 0 报运行时错误 |
| 自增自减 | `++  --` | 前置与后置均支持；操作数必须是可赋值左值 |
| 一元 | `-  +  !` | `!x`：0 → 1，非 0 → 0 |
| 比较 | `==  !=  >  <  >=  <=` | 结果为 int（1/0） |
| 逻辑 | `&&  \|\|` | **短路求值**，右侧未求值时在步骤中明确标注；操作数按「0=假，非0=真」判定 |
| 赋值 | `=  +=  -=  *=  /=  %=` | 赋值表达式有值（教学演示用） |
| 下标 | `a[i]` | 仅一维；下标越界报运行时错误 |
| 取地址 | `&var`、`&arr[i]` | 结果为指针值 |
| 解引用 | `*p` | 读/写均支持；空指针或未初始化指针解引用报运行时错误 |
| 调用 | `f(x, y)` | 用户定义函数 + 内置 printf/puts |

- ✅ 完整 C 优先级与结合性（子集内），包括 `*` 高于 `+`、比较低于算术、`&&` 高于 `||`、赋值右结合等。
- ✅ 括号分组。

### 1.4 语句与控制流

| 语句 | 支持 | 教学展示要点 |
| --- | --- | --- |
| 表达式语句 | ✅ | 求值轨迹 |
| `if` / `else` / 嵌套 | ✅ | 条件值 + 走向；悬空 else 归就近 if |
| `switch` | ✅ | 判别式必须整型（int/char）；case 标签为整型常量表达式；`default` 任意位置；**fall-through 穿透逐步展示**；`break` 跳出 |
| `while` | ✅ | 每次条件判断为独立步骤 |
| `for` | ✅ | init / condition / update 三段各自独立步骤；`for(int i=0;;)` 的 i 作用域限于循环 |
| `do { } while` | ✅ | 先执行后判断 |
| `break` | ✅ | 就近跳出循环或 switch |
| `continue` | ✅ | 跳到最近循环的下一轮（for 会先执行 update） |
| `goto` + 标签 | ✅ | 同一函数内前向/后向跳转；展示来源行与目标行 |
| `return` | ✅ | void 函数可裸 `return;` |
| 复合语句 `{}` | ✅ | 嵌套块作用域 |
| 空语句 `;` | ✅ | 如 `for(...;...;...) ;` |

### 1.5 函数

- ✅ 定义：`int add(int a, int b) { ... }`；参数按值传递。
- ✅ 指针参数与指针返回的参数传递：`void swap(int *a, int *b)` 支持（返回指针的函数不支持，见 §2）。
- ✅ 递归（如 factorial）；调用深度上限 100。
- ✅ 局部变量、全局变量访问。
- ✅ `int main()` / `int main(void)` 必须存在且仅一个，作为入口。
- ✅ 函数可定义在调用之后（不要求先声明后使用——教学宽松化，与 C99 不同，见 §3.4）。
- ✅ `return` 缺失：非 void 函数执行到函数末尾未 return → 运行时错误「缺少返回值」。

### 1.6 内置库函数（教学特供）

| 函数 | 支持 | 说明 |
| --- | --- | --- |
| `printf` | ✅ | 格式符支持：`%d %i %f %c %s %%`；转义支持：`\n \t \\ \" \' \0`；**不支持**宽度/精度/长度修饰（`%5d`、`%.2f`、`%ld` 遇到报不支持错误） |
| `puts` | ✅ | 输出字符串并换行 |

### 1.7 其他

- ✅ 注释：`//` 与 `/* */`（解析层处理，不产生步骤）。
- ✅ 数字字面量：十进制整数、浮点（`1`、`1.5`、`.5`、`2.`、`1e3`）；十六进制 `0x1F`；八进制 `010`；后缀 `u/U/l/L/f/F` 忽略（按最近类型处理）。
- ✅ 字符串字面量（仅作为 printf/puts 参数）。
- ✅ 布尔语义：一切条件按「0=假，非 0=真」。

## 2. v1.0 明确不支持清单

遇到以下特性时**不崩溃、不误解释**，而是在编译阶段给出「不支持特性」错误，附行:列与替代建议：

| 特性 | 错误提示要点 |
| --- | --- |
| `#include` 及一切预处理指令 | 「教学版无需 include，printf 已内置」 |
| `struct` / `union` / `enum` / `typedef` | 「v1.0 不支持自定义类型」 |
| 二维及多维数组 | 「仅支持一维数组」 |
| 二级指针 `int **p`、指针数组 `int *a[3]` | 「仅支持一层指针」 |
| 指针算术（`p+1`、`p++`、`p1-p2`、比较） | 「v1.0 指针仅支持 &、* 与赋值」 |
| `malloc` / `free` 等动态内存 | 「不支持动态内存」 |
| `sizeof` | 「不支持」 |
| 强制类型转换 `(int)x` | 「不支持类型转换」 |
| 位运算 `& \| ^ ~ << >>`（二元 `&` 与取址区分） | 「v1.0 不支持位运算」 |
| 三目 `?:` | 「请使用 if/else」 |
| 逗号运算符（含 `for(;;i++,j--)`） | 「不支持逗号表达式」 |
| 函数指针、递归以外的间接调用 | 「不支持函数指针」 |
| `scanf` / `gets` 等输入函数 | 「教学版不支持输入，请直接给变量赋值」 |
| 除 printf/puts 外的一切库函数（`strlen`、`abs`、`math.h` 等） | 「不支持该库函数」 |
| `goto` 跨函数 | 「goto 只能在同一函数内跳转」（跳到不存在标签 → 编译错误） |
| `const`、`static`、`volatile`、`register` 存储类 | 「v1.0 不支持存储类说明符」 |
| 变长数组 VLA、`int n; int a[n];` | 「数组长度必须是常量」 |
| 标签后无语句（`label:` 直接接 `}`） | 「标签后必须有语句（可用空语句 `;`）」 |
| K&R 风格函数、隐式 int | 「请写明返回类型与参数类型」 |
| `argv` / `argc`、命令行参数 | 「教学版 main 无参数」 |

## 3. 与标准 C 的**有意差异**（教学简化，均已在 UI/文档中说明）

1. **未初始化标量的读取是运行时错误**（标准 C 是未定义值）——帮助学生发现忘记初始化。
2. **不要求先声明后使用函数**——允许先写 main 后写辅助函数（降低初学者负担）。
3. **整数溢出不警告**：按环绕到 32 位有符号处理（与典型实现一致），不做 UB 检测。
4. **char 与 int 混算按 ASCII 码**：`'A' + 1` 结果为 int 66；赋回 char 再显示为字符。
5. **float/double 都按双精度**：不区分存储精度。
6. **数组初始化缺省补 0**（与 C 相同），但 `int a[3] = {1,2,3,4}` 报编译错误「初始化个数超过数组长度」（标准 C 同样非法，明确报错）。
7. **全局变量初始化必须是常量表达式**（与 C 相同，但只支持字面量四则运算）。
8. **不支持输入**（scanf）：所有输入用初始化/赋值替代。

## 4. 验收基准代码

以下代码必须能完整逐步可视化（也是完成标准的一部分）：

```c
int main() {
    int a = 1;
    int b = 2;

    if (a < b) {
        a++;
    }

    return 0;
}
```

以及：switch（含穿透）、for、while、do-while、短路 && 与 ||、数组遍历、函数调用、递归 factorial、goto（前向/后向）、基础指针（`&` 与 `*` 读写）。
