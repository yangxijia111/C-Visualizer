## 【Bug Fixes】

1. **ControlFlowPanel 事件重复/丢失**（本轮最重要修复）：
   旧实现 `history.slice(0, -1)` 隐含「当前 step 恰好 1 个 FlowEvent」——当前步 0 个事件时误吞上一事件、
   ≥2 个事件时中间事件在 past/now 重复。新实现按 step 边界严格划分（past=[cur-N, cur-1]，now=steps[cur]），
   提取为纯函数并覆盖 6 组单测 + 真实双事件程序回归。
2. **CodeEditor 重复 dispatch**：`[currentLine, errorLines]` 与 `[value, currentLine, errorLines]`
   两个 effect 内容完全相同，合并为一个；行高亮/错误行/编辑后状态行为不变。
3. **wasm 加载失败静默**：此前仅 `console.error`，界面仍显示「▶ 运行」误导用户；
   现在显示 `role=alert` 错误横幅并禁用运行按钮。
4. 附带：播放器步进/播放/时间轴边界逻辑提取为 `ui/playback.ts` 纯函数（行为不变，可单测）。

## 【Known Limitations】

- 支持范围为教学 C 子集（详见 [SUPPORTED_C.md](SUPPORTED_C.md)）；不支持 struct/二维数组/指针算术/动态内存等
- 与标准 C 的有意教学差异（未初始化读取报错等）已在文档声明
- 首次加载需下载约 800 KB wasm 资源（浏览器有缓存）
- 桌面端优先；窄窗口为「基本可用」的堆叠布局，非移动端重设计
- JS bundle 未做代码分割（单 chunk ≈ 954 KB，Vite 有 >500KB 警告）
- CI 的 annotation：actions/checkout@v4 与 setup-node@v4 运行时被强制升到 Node 24 的常规迁移提示（非失败）
